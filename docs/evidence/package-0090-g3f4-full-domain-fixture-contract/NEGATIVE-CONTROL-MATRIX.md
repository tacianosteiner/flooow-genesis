# Negative controls

Each of 13 case models has all 13 one-dimension controls. Only its semantic field changes; the manifest digest is recomputed so denial is not merely checksum failure. All required top-level fields and every model join also have omission checks. JSON runtime-proof booleans never grant eligibility. These are model validator results; none is an actual frozen SQL negative-control PASS. The exact per-case matrix is in NEGATIVE-CONTROL-MATRIX.json.

============================================================
3. DESIGN RATIONALE
============================================================

Record the project-authority rationale:

O8 is selected because the target gap concerns credential
inheritance across a transition.

The protected object must permit analysis of whether semantically
relevant credential state persists from predecessor to successor
without prematurely defining the persistence mechanism.

Selecting:

- credential material,
- credential identity,
- credential class,
- authentication capability,
- custody,
- authority,
- binding,
- credential-bearing capability,
- or endpoint manifest

as the root protected object would prematurely narrow or couple the
gap to one particular representation or security dimension.

INHERITED_CREDENTIAL_STATE provides the semantic object required to
ask the inheritance question while leaving the following unresolved
questions independent:

TRANSITION
POSTMASTER_CONTEXT_BINDING
INTERNAL_SCOPE_AND_EXCEPTIONS
EXHAUSTIVE_ATOMIC_BOUNDARY

This decision intentionally does NOT answer those questions.

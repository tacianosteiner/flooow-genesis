## Mission

Preserve and continuously evolve a governed economic-intelligence
capability so FLOOOW does not merely analyze a market once and freeze
the interpretation.

``` text
observe reality
-> discover relevant economic ideas and competing explanations
-> convert ideas into explicit lenses and falsifiable hypotheses
-> bind hypotheses to observable evidence
-> compare competing explanations
-> update beliefs as evidence changes
-> explore possible worlds and regime changes
-> propose bounded decisions and experiments
-> observe actual outcomes
-> measure which explanations worked, where, and under what conditions
-> learn
-> repeat
```

Core rule:

``` text
ECONOMIST != AUTHORITY
BOOK != TRUTH
MODEL != REALITY
FORECAST != ACTUAL
CONSENSUS != PROOF
POPULARITY != EVIDENCE
```

Economic thinkers, papers, books, institutions, forecasts and external
research are contextual evidence and hypothesis sources. Canonical
Economic Truth, institutional evidence, authority, execution,
reconciliation and actual outcomes remain governed by existing FLOOOW
contracts.

## Five continuous loops

### A --- Economic Thought Radar

Continuously discover material changes in economic thinking from
foundational economists and primary texts; current leading economists;
peer-reviewed journals and working papers; Nobel lectures; NBER/CEPR;
central banks/BIS; IMF, World Bank, OECD and UN; universities/research
labs; replications, critiques and credible dissent.

Every material source receives provenance, date/version, claims,
counterclaims, empirical status, applicability and ADOPT / ADAPT /
REJECT / WATCH classification.

### B --- World Signal Radar

Continuously observe AI/automation, productivity, labor/task
reallocation, innovation, demographics, migration, climate/energy,
geoeconomic fragmentation, trade/supply chains, monetary/financial
architecture, tokenization, institutions/regulation, platform power,
capital/debt/liquidity and consumer welfare.

### C --- Hypothesis Competition

Different lenses may explain the same observation. No lens wins by
author reputation. Example: declining sales may generate Marshall
(elasticity), Keynes (demand), Schumpeter/Aghion/Howitt (creative
destruction), Coase/Williamson (transaction costs), Hayek (missing
distributed information), Kahneman/Tversky (decision bias),
Acemoglu/North (institutional/power shift).

### D --- Possible Worlds

2050 is never a single point forecast. Maintain explicit possible worlds
with assumptions, leading indicators, contradictions and transition
conditions: AI abundance, AI concentration, slow diffusion, fragmented
globalization, demographic squeeze/dividend, climate-energy constraint,
tokenized finance, expensive capital, innovation renaissance,
institutional deterioration/renewal and combinations.

### E --- Outcome Learning

For every material lens application preserve CONTEXT, OBSERVATION_TIME,
LENS_VERSION, HYPOTHESIS, PRIOR, EVIDENCE_USED, COUNTEREVIDENCE,
CONFIDENCE, FALSIFIERS, PREDICTED_OBSERVABLES, DECISION_IF_ANY,
ACTUAL_OUTCOME, CALIBRATION_ERROR, EXPLANATORY_RESULT, POSTERIOR and
LESSON.

## Two-memory architecture

1.  **Intellectual memory** --- theories, mechanisms, claims, sources,
    critiques and revisions.
2.  **Performance memory** --- where/when a lens explained or predicted
    reality, its error and regime dependence.

Never collapse them.

## Competing-explanation engine

``` text
event / signal
-> generate finite candidate explanations
-> bind each explanation to a versioned lens
-> derive evidence requirements
-> retrieve support and contradiction
-> identify missing high-value information
-> update beliefs
-> compare explanations
-> propose discriminating experiment / next-best-information
-> observe outcome
-> recalibrate
```

## Anti-dogma rules

Forbidden: author prestige -\> truth; Nobel -\> production authority;
popularity -\> empirical validity; one school -\> universal ontology;
macro forecast -\> company forecast; correlation -\> causation;
consensus -\> certainty; LLM synthesis -\> evidence; historical success
-\> permanent winner; current regime -\> permanent regime; scenario
probability -\> Economic Truth; confidence -\> execution authority.

Required:

``` text
SOURCE
-> CLAIM
-> MECHANISM
-> ASSUMPTIONS
-> OBSERVABLES
-> COUNTEREVIDENCE
-> FALSIFIER
-> CONTEXT
-> CALIBRATION
-> GOVERNED USE
```

## Kill criteria

Do not promote if outputs become unfalsifiable narratives; provenance is
unreproducible; model competition cannot beat simple baselines;
confidence is uncalibrated; scenarios are mistaken for truth; rhetorical
plausibility is rewarded over observed accuracy; maintenance cost
exceeds demonstrated decision value; Room availability depends on
research; or hidden authority escalation appears.

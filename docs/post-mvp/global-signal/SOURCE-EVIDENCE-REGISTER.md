## Evidence semantics and counts

Every row is a substantive assertion or access observation. `SOURCE` names the publisher, `URL` is the direct primary page. PUBLICATION_DATE is the displayed date when established; observation date is never substituted. `DIRECT_QUOTE_IF_NEEDED=NONE` for every row; CLAIM and PARAPHRASE are the same concise paraphrase. `REPRODUCED=NO` for every row: checking documentation does not reproduce commercial data accuracy, coverage, sales, forecasts or access entitlement. `CONTRADICTED=UNKNOWN` means no adjudicated external contradiction test was performed, not agreement. Access failures are retained as tool-local observations. OFFICIAL_DOCUMENTATION verifies the existence of a description, not operational delivery. Some pages were available only through official indexed snippets; these are explicitly marked below.

## Interpretation and preservation boundary

The catalog and matrix reference these IDs. Design choices, lead-time propositions and cross-market routes are FLOOOW research hypotheses, not vendor assertions or measured observations. No sample, error distribution, causality estimate, access token or paid dataset was obtained. Mutable public links can change; this register preserves dated paraphrases, not a content-addressed raw capture. Before empirical qualification, retain permitted raw snapshots/hashes, complete query/filter/account context, release versions and rights evidence. Documentation discovery is complete for the initial bounded cohort; data/API/license qualification remains open.

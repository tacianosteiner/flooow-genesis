## Promotion states and evidence

DISCOVERED -> RESEARCH_APPROVED -> DATA_READY -> BASELINE_READY -> BENCHMARKED -> ADVERSARIAL_PASSED -> SHADOW -> PILOT -> PRODUCTION_ELIGIBLE -> PRODUCTION_APPROVED -> MONITORED -> SUPERSEDED / REVOKED.

Discovery records source and hypothesis. Research approval names owner and bounded scope. Data readiness proves rights, quality and lineage. Baseline readiness proves a reproducible comparator. Benchmark and adversarial gates freeze datasets and report dangerous errors. Shadow requires separate authorization for read-only access, isolation and monitoring; pilot requires a bounded population and loss cap. Eligibility requires all quality, provenance, license, security, latency, cost, shadow and adversarial gates. Explicit production approval binds artifact, scope, accountable authority and rollback. Missing evidence blocks transitions; elapsed time never promotes a capability.

PRODUCTION_ELIGIBLE != PRODUCTION_APPROVED

Transitions require immutable evidence references, previous/new state, actor, timestamp, artifact digest, reason and exact approval scope. Any state can be revoked; revocation disables experimental outputs and preserves audit evidence. Supersession requires an explicitly accepted successor. Monitoring covers false matches, drift, error cost, privacy, authority violations and correction rate. Rollback must preserve Room operation and existing truth; independent operational proof is required before release.

# FLOOOW --- Post-MVP Acceleration Roadmap

Status: PREPARED_POST_MVP_RESEARCH Implementation authority: NONE MVP
critical path impact: NONE Promotion: EXPLICIT PROJECT-AUTHORITY
DECISION REQUIRED

## Mission

Use the MVP build window to reduce post-MVP discovery latency. Research
may produce architecture candidates, source catalogs, threat models,
contracts, evaluation plans, implementation work packages and promotion
criteria. It must not modify MVP runtime, canonical contracts,
migrations, PACKAGE-0090, or production behavior.

## Strategic sequence

### P0 --- Runtime Evidence Harvest

After MVP closure, capture real Decision Room traces, evidence gaps,
reconciliation failures, authority transitions, latency/cost and human
interventions. Exit: representative runtime corpus and failure taxonomy.

### P1 --- REA-X / Economic Epistemic Control Plane

Formalize Evidence → Admissible Evidence → Economic Claim → Economic
Truth → Decision → Authorized Action → Outcome → Learning Evidence.
Exit: typed authority, temporal invalidation, completeness/contradiction
propagation and threat model.

### P2 --- Global Economic Commerce Graph (GECG)

Build above ordinary product graphs: Product/Variant/GTIN, Brand,
Supplier, Factory, Merchant, Marketplace, Creator, Content, Demand,
Offer, Inventory, Freight, Duty, Tax, Ads, Returns, Price, Margin,
Evidence, Authority, Decision, Action and Outcome. Rule: similarity !=
identity; source existence != source authority; product graph !=
economic truth.

### P3 --- Commerce Signal Intelligence

Connect Amazon, Mercado Livre, TikTok Shop, SmartScout, FastMoss,
Kalodata, EchoTik, ChanMama, Feigua, Shoplus, PiPiADS, Minea, FindNiche,
ImportYeti and future qualified sources through Raw Signal → Provenance
→ Identity Resolution → Freshness → Contradiction → Belief → Economic
admissibility.

### P4 --- Agentic Commerce Interoperability

Prepare protocol-neutral adapters for MCP, A2A, UCP, ACP, AP2, WebMCP,
agent identity/trust schemes and relevant payment rails. Rule: protocol
success != FLOOOW authority.

### P5 --- Governed Agent Skills Supply Chain

Discover → Fetch → Provenance → Integrity → Security Scan → Capability
Classification → Version/Lock → Sandbox → Evaluation → Qualification →
Promotion → Revocation. Prepare multi-registry discovery,
packaging/versioning, signatures, SBOM, scanner benchmarks and sandbox
policy.

### P6 --- Agent Identity, Delegation & Economic Authority

Separate agent identity, principal identity, delegation, intent,
economic authority, payment authority, action acceptance and runtime
execution authority. No authority inheritance.

### P7 --- Decision-to-Execution Plane

Connect governed decisions to actions only after REA-X and authority
boundaries pass adversarial review. Prepare action ledger, idempotency,
compensating actions, receipts, replay and reconciliation.

### P8 --- LEWM

Living Economic World Model remains context/hypothesis, never automatic
Economic Truth. Prepare world-state schema, source classes, scenarios,
uncertainty and temporal updates.

### P9 --- Causally Qualified Learning

Observed outcome != causal evidence; causal evidence != automatically
admissible learning. Prepare attribution classes, counterfactual
evaluation, learning-admissibility gates and rollback.

### P10 --- Autonomous Economic Operating System

Sense → Reconcile → Know → Decide → Authorize → Act → Observe →
Attribute → Learn. Increase autonomy only with demonstrated evidence
quality, bounded authority, reversible execution and measured outcomes.

## Prepared-first package for every phase

Architecture decision dossier; source catalog; threat model;
contracts/interfaces; benchmark/evaluation plan; implementation work
packages; dependency graph; promotion gate; rollback/revocation
strategy; explicit non-goals.

## Promotion rule

Everything remains research until explicitly promoted after MVP
stability, empirical runtime evidence, overlap analysis, threat
modeling, deterministic tests, adversarial review, rollback design,
bounded authority and measurable expected value.

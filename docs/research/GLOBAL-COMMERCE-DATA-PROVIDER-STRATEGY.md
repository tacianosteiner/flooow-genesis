## Decision boundary

Buy or license observations where access, permitted retention and independent test quality warrant it. Build FLOOOW's differentiating layer: cross-market physical-product identity, independence-aware corroboration, Brazil gap tests, supplier/importability verification, calibrated provisional economics and learning against reconciled outcomes. Neither a provider's estimated GMV nor an ad/search trend is a sale. No vendor is approved for use by this document.

## Procurement-grade trial

Use the same blinded candidate set across vendors: Brazil and China examples, hard-negative product variants, known live/post/listing IDs, independent purchase or seller-authorized outcome records when available, and time-split holdouts. Record coverage denominator, observation latency, identity precision/false merges, estimate error, stale/deleted records, independent-origin count, source revisions and export reproducibility. Test supplier/trade links independently. Preserve rejected samples and provider methodology claims separately from verified results.

Ask each vendor for exact territory/category coverage, dataset origin, refresh and history, API/bulk/alert entitlement, product/creator ID stability, error and correction process, processing location, retention, combining/derivative and UI-display rights, termination/deletion, rate limits, price and service terms. No credential, live call, purchase, crawler or integration is authorized here. **Reject for now** any path that requires unauthorized collection or promotes estimates into canonical economic truth. Build/defer/buy follows measured trial quality, economics and license review.

## Critical distinction: Value Tracked vs Value Proven

Public Celonis behavior allows historical realized value to be represented
even when that value originated outside the current Celonis evidence universe,
including other tools or spreadsheet-based records.

Framed value can also be revised as expectations, resources or observed
performance change.

This does not mean the value is false.

It establishes a narrower architectural distinction:

VALUE_TRACKED
!=
VALUE_PROVEN_BY_A_CANONICAL_ECONOMIC_EVIDENCE_CHAIN

The FLOOOW research candidate is therefore not generic value management.

It is proof-bearing economic claims.

## Economic Epistemic Conservation

An economic assertion must never acquire greater certainty, completeness or
authority than the admissible economic evidence supporting it.

Required distinctions include:

PARTIAL != COMPLETE

UNKNOWN != ZERO

UNQUANTIFIED != ZERO

MISSING != FALSE

CONTRADICTED != RESOLVED

INFERRED != OBSERVED

ESTIMATED != OBSERVED

PREDICTED != ACTUAL

OPPORTUNITY != REALIZED_VALUE

CLAIM != TRUTH

ACTION_AUTHORITY != CLAIM_AUTHORITY

CLAIM_AUTHORITY != PROVEN_TRUE

## Completeness-Preserving Aggregation

The existence of known quantified components must not silently authorize a
complete aggregate when required components remain unquantified.

Example:

ADS_LEAKAGE=40000 KNOWN

RETURNS_LEAKAGE=25000 KNOWN

FREIGHT_LEAKAGE=UNQUANTIFIED

TAX_LEAKAGE=10000 KNOWN

Then:

KNOWN_QUANTIFIED_COMPONENTS=75000

does not imply:

TOTAL_ECONOMIC_LEAKAGE=75000

Existing FLOOOW contract behavior provides a concrete example:

ANY REQUIRED STAGE = UNQUANTIFIED

→ totalQuantifiedLeakage = null

Candidate primitive:

COMPLETENESS_PRESERVING_AGGREGATION

Status:

AHEAD_BY_DESIGN_CANDIDATE

## Economic contradiction propagation

Source disagreement alone is not differentiation.

The stronger candidate is propagation of unresolved economic contradiction
into dependent claims.

Example:

COGS_ERP=80

COGS_INVOICE=91

COGS_LANDED=103

If no admissible authority/evidence resolves the contradiction:

COGS=CONTRADICTED

If final margin requires COGS:

FINAL_MARGIN=NOT_ASSEMBLED

A recommendation depending on final margin may therefore become:

BLOCKED

Candidate:

ECONOMIC_CONTRADICTION_PROPAGATION

Status:

AHEAD_BY_DESIGN_CANDIDATE

No claim is made that Celonis cannot implement such behavior.

Its exact public equivalent was not established in this REA.

CLAIM_AUTHORITY

is separate from:

## Causal inference

Celonis materially weakens any FLOOOW claim based merely on causal reasoning.

Causal inference, forecasting and simulation should therefore be treated as
inputs into economic reasoning rather than Economic Truth authority.

A model may produce:

DECISION_X_GENERATED_R327418_OF_REALIZED_MARGIN

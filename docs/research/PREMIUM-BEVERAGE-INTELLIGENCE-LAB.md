# FLOOOW — Premium Beverage Intelligence Lab

Status: POST-ROOM EXPERIMENT DESIGN
Initial vertical: imported wines + premium imported beer
Implementation authority: NONE

## Why this vertical
A partner already operates with 50+ wine labels from multiple countries and premium imported beers in emporiums and large supermarket chains. This is a strong real-world laboratory for import economics, assortment, physical retail, retail media, shopper preference and repeat purchase.

## Target model
Traditional:
IMPORT -> STOCK -> SALESPERSON -> RETAILER -> PROMOTION -> WAIT

FLOOOW:
PRODUCT INTELLIGENCE
+ RETAILER INTELLIGENCE
+ STORE INTELLIGENCE
+ SHOPPER INTELLIGENCE
+ MEDIA INTELLIGENCE
+ ECONOMIC TRUTH
-> PORTFOLIO DECISION

## Beverage intelligence object
Potential fields:
product_id, brand, country, region, producer, varietal, vintage, landed_cost, wholesale_price, retail_asp, retailer, store_cluster, inventory, sell_in, sell_out, sell_through, repeat_rate, promotion, media_exposure, qr_interactions, shopper_segment, basket_affinities, contribution.

## Assortment intelligence
Question:
Which label belongs in which store?

Signals:
premium shopper density, basket composition, complementary products, price sensitivity, local sell-through, repeat, competition, shelf space, retailer margin and importer contribution.

## Closed-loop retail media
SHOPPER EVIDENCE -> AUDIENCE -> MEDIA EXPOSURE -> PURCHASE -> REPEAT -> CONTRIBUTION

Primary metrics:
incremental units, incremental buyers, new-to-brand, repeat, basket adjacency, contribution, retailer margin, importer contribution.

Do not optimize only ROAS.

## AI Sommelier
Possible flow:
shopper context + budget + food + taste + real store availability + price + inventory -> recommendation.

## QR / GS1 Digital Link
Bottle -> product identity -> origin/winery/grape/vintage -> pairing/story/traceability -> store availability -> AI sommelier -> observed interaction.

## Shelf intelligence
Store image -> product detection -> SKU recognition -> facings -> missing SKU -> competitor presence -> SHELF CONTRADICTION.
